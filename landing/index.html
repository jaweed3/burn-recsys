Architecture

Two-stage retrieval.
Single binary.

Stage 1: HNSW ANN retrieves the top-100 nearest item vectors from 7,988 candidates. Stage 2: The neural ranker scores each candidate with a sigmoid forward pass.

Worker pool architecture.
One model clone per thread.
Zero lock contention. mpsc dispatch.

  • ✓ HNSW ANN — instant-distance, Euclidean L2
  • ✓ Neural Ranker — sigmoid score, sort descending
  • ✓ Worker Pool — mpsc channel, zero contention

— Architecture Notes
Pipeline

From CSV to recommendation.
In seven commands.

01

Load

Polars LazyFrame scans CSV in a single multithreaded pass. Re-indexing builds hash maps in O(n). 694K rows in <200ms.

02

Train

Adam optimizer, binary cross-entropy, early stopping by HR@k patience. Auto-saves best.mpk + config.toml. 5 epochs, ~4 minutes on M4.

03

Index

All item embeddings feed into an HNSW graph at server startup. instant-distance, Euclidean L2. Retrieval: ~0.12ms.

04

Serve

Axum HTTP API. mpsc worker pool. One model clone per thread. POST /recommend returns ranked items in <1ms. OpenTelemetry metrics out of the box.
